# Retired weekly journal archive

The raw weekly and fortnightly JSON archive was moved outside the deployable repository on 26 August 2026 because it contains personal account balances, cash amounts, transaction sizes and share quantities.

All 17 legacy public URLs remain mapped through `legacyJournalRedirects` to the five privacy-safe monthly reviews. The original history is preserved in the private archive; the public site retains its reasoning, percentage results, decisions and lessons through the monthly review record.
